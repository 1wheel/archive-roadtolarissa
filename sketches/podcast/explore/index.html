Design explorations

Six alternative views of the same press-tour data, each built by a separate agent.

  1. The Circuit — 40 most-booked guests, one row each, dots colored by host, red bars under tours
  2. Host × host matrix — which hosts share a booking pool (Ezra×Terry: 14 tours)
  3. Guest arcs — the same corridors as an arc diagram; Ira Glass is an island
  4. Stop order — sankey of 1st/2nd/3rd stops + who opens vs. closes a tour
  5. Tour speed — beeswarm of tour spans; fastest/slowest annotated
  6. Tour seasons — monthly tour stops by host + rolling share of episodes that are tour stops
